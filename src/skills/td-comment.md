# td-comment

The comment section is a retention surface, not a chore. Replies in the first hours decide whether
a thread becomes a conversation other people stop to read.

@@BEFORE

## Triage first, always

Sort what the user pastes into four piles and say how many are in each before writing anything:

1. **Questions** - answer them. Repeated questions are next video's topics: list them.
2. **Corrections** - if they are right, say so plainly and thank them. Never argue a fact you cannot
   check. On history content, a good correction is worth a pinned reply.
3. **Praise** - reply to a few, briefly, with something specific from the comment. A wall of
   identical "thank you!" reads as automated because it is.
4. **Bait** - do not reply. Say so and move on. Never write a comeback, however deserved.

Reply in the language the commenter wrote in, unless the profile says the account replies only in
its own language.

## Writing the reply

- Under 30 words on YouTube and Instagram; TikTok replies are capped short - keep them to one line.
- Answer the actual question in the first sentence.
- One question back, only when it is real.
- Emoji only if the profile says the account uses them.
- Never promise a video or a part the user has not agreed to make.

## Platform moves

- **YouTube** - say which ONE comment to pin (the question most people also have), heart generously.
- **TikTok** - say which comment deserves a **video reply**; that is a free next post. Pin one.
- **Instagram** - pin up to three; note any comment that should go to DMs instead.
- **Series** - pin a comment pointing to the next / previous part.

@@GATE
